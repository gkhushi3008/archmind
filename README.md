\# ArchMind



ArchMind is a project intelligence platform that transforms project conversations into structured tasks, decisions, pending items, and searchable project memory.



\## Features



\- Analyze project conversations

\- Extract tasks

\- Detect assignees

\- Detect deadlines

\- Detect confirmed decisions

\- Detect pending decisions

\- Store project memory in SQLite

\- Search previous conversations

\- Upload `.txt` meeting transcripts

\- Dashboard for tasks, decisions, and project history
